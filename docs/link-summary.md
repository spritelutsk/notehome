# «Кратко о ссылке»

`server/link-summary.js` + ручка `GET /api/nodes/link-summary?url=…`.

Пользователь вставляет URL в форму создания ссылки и жмёт кнопку — сервер сам скачивает страницу,
вырезает из неё текст и просит `claude` придумать короткое название и описание на русском.
Результат подставляется в поля формы; ничего не сохраняется само.

## Почему это самое опасное место в проекте

Ручка заставляет **сервер** ходить по адресу, который назвал **пользователь**. Это классический
SSRF: без защиты через неё можно достучаться до чего угодно внутри сети — до localhost, до соседей
по LAN, до метаданных облака. Отсюда все меры ниже. Меняя этот файл, не убирайте их «для простоты».

### Проверка адреса

`isPrivateIp()` отсекает loopback, `10/8`, `172.16/12`, `192.168/16`, `0.0.0.0/8`,
link-local `169.254/16` (это же адрес метаданных у облачных провайдеров), а для IPv6 — `::1`,
`fc00::/7`, `fe80::/10`. Отдельно разбирается форма `::ffff:127.0.0.1`: без нормализации
IPv4-mapped адрес проскочил бы мимо всех проверок IPv4.

### Пиннинг IP

Проверять имя хоста и потом отдавать его же HTTP-клиенту нельзя: между проверкой и подключением
DNS-запись может смениться (rebinding через короткий TTL). Поэтому `requestPinned()` подключается
**по уже проверенному IP**, а исходное имя передаёт только в заголовке `Host` и в TLS SNI.

### Редиректы вручную

Автоматическое следование за редиректами свело бы проверку на нет: страница ответила бы `302` на
внутренний адрес. `safeFetch()` разбирает каждый хоп сам и прогоняет через полную проверку —
максимум 5 переходов, дальше `too_many_redirects`.

### Прочие ограничители

- только `http:` / `https:`
- только `Content-Type: text/html`
- 8 секунд на запрос
- не больше 300 КБ тела (дальше сокет рвётся — для `<head>` хватает)
- не больше 12 000 символов текста уходит в промпт
- rate limit: 20 запросов в час на IP (`server/index.js`) — это ещё и защита расхода подписки

## Вызов claude

Запускается локальный CLI `~/.local/bin/claude`, уже залогиненный под подпиской владельца
машины — отдельного API-ключа в проекте нет. Флаги: `--model haiku`, `--output-format json`,
`--allowedTools ''` (никаких инструментов), `--permission-mode bypassPermissions`, таймаут 45 с.

В промпте прямо сказано игнорировать любые инструкции, встреченные в тексте страницы — это
данные, а не команды. Защита от prompt injection здесь неполная по своей природе, поэтому важно,
что модели нечего исполнять: инструменты отключены, а результат — только две строки, которые
подставляются в поля формы.

Ответ парсится с запасом: сначала внешний JSON от CLI, потом `result` очищается от возможной
```-обёртки и парсится как JSON, title обрезается до 500 символов, description — до 2000.
Любая осечка на этом пути превращается в `summary_failed`, подробность уходит в лог сервера,
а не пользователю.

## Коды ошибок

`invalid_url`, `url_not_allowed`, `fetch_failed`, `not_html`, `empty_page`,
`too_many_redirects`, `summary_failed`. Русские тексты для них — в `ERROR_MESSAGES`
в `public/js/app.js`.
