## Инфраструктура (с 2026-08-06)

- [ ] **Домен недоступен из интернета, и пробросом это не чинится — провайдер за CGNAT.**
      Проверено 2026-08-08: WAN-адрес роутера (TP-Link TL-WR840N, `192.168.1.1`) —
      `100.64.76.40`, это RFC 6598 (`100.64.0.0/10`), а интернет видит `185.208.231.232`.
      Правило на роутере откроет порт только на адресе внутри сети провайдера; входящие
      соединения до роутера просто не доходят. Глобального IPv6 тоже нет — обойти нечем.
      Варианты: белый IP у провайдера (тогда проброс 443 действительно решает задачу),
      Tailscale Funnel (имя будет `*.ts.net`), обратный туннель через VPS (сохраняет имя
      duckdns). Подробности — в `docs/sessions/2026-08-08.md`.
      **Решено через Tailscale Funnel:** приложение доступно снаружи по
      `https://sergey.taile46903.ts.net`, админка наружу закрыта. Пункт остаётся открытым
      только на случай, если однажды понадобится именно домен DuckDNS.
- [ ] **Перезагрузить Pi.** Проверит разом две непроверенные вещи: порядок

      но реального ребута после переезда БД и обновления Node не было.
