# CHANGELOG

Заметные изменения проекта. Формат: свежие сверху, дата — день изменения.
Подробности по каждой рабочей сессии — в `docs/sessions/` (журнал не публикуется, живёт
только на рабочей машине).

## 2026-08-08

### Добавлено

- **Переключение языка интерфейса доведено до рабочего состояния** (украинский, русский,
  английский). PR #1 добавил словарь и селектор в окне «Аккаунт», но переключение не работало:
  обработчик вызывал несуществующую `renderStaticTexts()`, `ReferenceError` гасился общим
  `catch`, и пользователь видел «не удалось сохранить настройку» при успешно сохранённой
  настройке. Появились сама `renderStaticTexts()`, разметка ключами `data-t` / `data-t-title` /
  `data-t-placeholder` и перерисовка данных при смене языка. К интерфейсу из 191 ключа словаря
  было подключено 6; сейчас переводится весь видимый текст — 312 ключей, включая тосты,
  подтверждения, пустые состояния, панель управления, блокнот и терминал.
- **Первый автотест:** `test/i18n.test.js` (`npm test`) — грузит настоящие `index.html` и
  `app.js` в jsdom, подменяет ответы сервера и проверяет переключение языка в DOM.
  jsdom добавлен в `devDependencies`.
- **Вкладка «Инструкция»** — страница с описанием интерфейса и назначением каждой кнопки
  (верхняя панель, дерево, панель над содержимым, меню элемента, все модальные окна).
  Разметка статическая, в `public/index.html`; админские строки и блок помечены
  `.help-admin-row` / `#help-admin` и показываются только администраторам. Видимость всего
  админского UI собрана в одну функцию `applyAdminVisibility()` в `public/js/app.js`.
- **Доступ снаружи через Tailscale Funnel** — `https://sergey.taile46903.ts.net`. Проброс
  портов невозможен: провайдер держит абонента за CGNAT (WAN-адрес роутера — `100.64.76.40`
  из RFC 6598). Новый vhost `scripts/nginx-spritenote-funnel.conf`: сохраняет CSP и security-
  заголовки, задаёт `X-Forwarded-Proto https` (TLS снимает Tailscale) и **закрывает `/api/admin`
  наружу** — админка с файловым менеджером и веб-терминалом доступна только из LAN и внутри
  тайлнета. Домен DuckDNS продолжает работать внутри сети.

### Безопасность

- **`GET /api/admin/project-zip` больше не кладёт `.env` в архив** — там пароль к БД и токен
  DuckDNS. Список исключений — `ZIP_EXCLUDES` в `server/routes/admin.js`.
  `scripts/init-db.sql` осознанно остаётся в архиве — он часть исходников.
- **В `scripts/init-db.sql` вернулся плейсхолдер `CHANGE_ME`** вместо настоящего пароля от БД,
  попавшего туда при развёртывании. Сделано перед публикацией проекта на GitHub: из истории git
  такое уже не убрать. На работу сервиса не влияет — пользователь БД давно создан, боевой пароль
  живёт в `.env`. При развёртывании с нуля плейсхолдер, как и раньше, заменяется руками.
- **Журнал сессий `docs/sessions/` выведен из-под контроля версий** (`.gitignore`): он описывает
  конкретный сервер — имена узлов, адреса, устройство доступа снаружи, — а не проект.

### Изменено

- **Словарь переводов перестроен** из трёх параллельных словарей (`uk`/`ru`/`en`) в
  «ключ → `[uk, ru, en]`». Языки лежат в одной строке: добавляя текст, невозможно молча
  забыть про один из них. Заодно снято лишнее экранирование апострофов, из-за которого
  английские строки показывали обратный слэш в `doesn\'t`, `won\'t` и подобных.
- **`project-zip` не тянет `node_modules`:** архив похудел с 18 МБ / 1841 файла до
  224 КБ / 56 файлов. Содержимое восстанавливается через `npm install`.

## 2026-08-07

### Добавлено

- **Настройки пользователя на аккаунте.** Колонка `users.settings` (JSON в TEXT),
  спецификация в `server/user-settings.js`, ручка `PUT /api/auth/settings`. Настройки приезжают
  вместе с пользователем в ответах `/me`, `/login`, `/register`.
  Первая настройка — режим отображения папки «плитка/список».
- **Автомиграции схемы.** `server/schema.js` → `ensureSchema()` вызывается перед `listen()`
  и доводит уже развёрнутую БД до актуальной схемы. Обновление снова сводится к
  «git pull + restart», ручной SQL не нужен. При ошибке процесс падает, а не поднимается
  наполовину рабочим.
- **Документация проекта:** `AGENTS.md`, `TODO.md`, этот файл, и `docs/` по крупным модулям —
  `data-model.md`, `frontend.md`, `import-export.md`, `link-summary.md`, `admin-and-terminal.md`.

### Изменено

- **Режим «плитка/список» запоминается для каждого пользователя,** а не одним значением
  в `localStorage` на браузер. Две учётки на одном компьютере больше не делят настройку,
  а выбранный режим переезжает вместе с аккаунтом на другое устройство.
- **Импорт JSON больше не создаёт дубли.** Добавляется только то, чего нет; узел опознаётся
  по тройке «родитель + тип + имя» (имя — без учёта регистра и пробелов по краям). Повторный
  импорт того же файла теперь пустая операция. Новые элементы попадают внутрь существующей
  папки, а не в её копию; дубли внутри одного файла тоже схлопываются. Ответ ручки получил
  поле `skipped`, интерфейс показывает «Добавлено: N, уже было: M».
- **Иконки интерфейса переведены с emoji на inline-SVG.** На Linux эмодзи-шрифт обычно не
  установлен (на этой Pi его нет), и все `📁 🔗 📝 📄` рисовались пустыми квадратиками.
  Иконки собраны в `ICONS` в `public/js/app.js`, статические кнопки размечены `data-icon`,
  лупа в поле поиска — фоновым SVG. Emoji в интерфейсе больше не используются.

### Исправлено

- Кнопка «Кратко о ссылке» больше не теряет свою иконку после запроса: подпись на время
  загрузки подменяется через `innerHTML`, а не `textContent`.
